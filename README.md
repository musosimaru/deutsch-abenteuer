# Deutsch-Abenteuer

Небольшой интерактивный сайт для ученика третьего класса на основе фотографий страниц учебной тетради по немецкому: Einheit 0 (Willkommen!) и Einheit 1 (Hallo, Freunde!, Grußformeln, Wie heißt du?, Wie geht's?).

## Как запустить

Откройте файл `index.html` в браузере на компьютере или телефоне. Никакой установки, регистрации, API или доступа к интернету не требуется.

## Как играть

- Выберите язык интерфейса: Italiano (по умолчанию) или Русский.
- Откройте одну из шести тем или финальный «Супермикс».
- Пройдите 8 заданий (12 в финале): выбор ответа, распознавание на слух, вставка слова, составление фразы.
- За правильные ответы выдаются звёзды, лучший результат хранится в браузере этого устройства.
- Нажмите «🔊» для озвучивания немецкой фразы.

## Озвучка

Сайт использует встроенный Speech Synthesis браузера, а не заранее скачанные аудиофайлы. Для корректного произношения желательно, чтобы на телефоне/ПК был доступен немецкий голос Text-to-Speech (de-DE). Наличие голосов и работа без сети зависят от браузера/системы.

## Опубликовать как ссылку

Загрузите `index.html` в статический хостинг (например, GitHub Pages или Netlify). Здесь нет сервера и нет внешних зависимостей. Сайт не отправляет результаты на сервер.

## Технические замечания

Прогресс хранится в `localStorage`. При открытии HTML с `file://` постоянное хранение может зависеть от браузера. Для постоянной ссылки и предсказуемого сохранения лучше использовать HTTPS-хостинг.

Это новый материал по тем же темам, а не точная цифровая копия страниц учебника. В отдельный раздел дополнительно включены числа 1–12 для практики.
